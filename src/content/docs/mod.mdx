## What it needs

Subscribe to these on the Steam Workshop:

- [CBA_A3](https://steamcommunity.com/sharedfiles/filedetails/?id=450814997)
- [ACE](https://steamcommunity.com/sharedfiles/filedetails/?id=463939057)
- [Zeus Enhanced](https://steamcommunity.com/sharedfiles/filedetails/?id=1779063631)
- [The rest of the battalion's modset - Workshop collection link]

## Install

<Steps>

1. Download the latest release and unzip it. You get a folder called `@jmfsb`.

2. Put `@jmfsb` in your Arma 3 folder, or anywhere you keep local mods.

3. In the Arma 3 Launcher, open **Mods > Add local mod...** and pick the `@jmfsb` folder.

4. Enable it together with the Workshop mods above and start the game.

</Steps>
