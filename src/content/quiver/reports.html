Every card has REMARKS at the bottom. REQ lines must be filled.

6-LINE CASEVAC - opens a task, high priority

  1. Pick-up site location (grid)
  2. Number of patients
  3. Priority of patients: urgent / priority / routine
  4. LZ security: green / yellow / red
  5. Marking method: smoke, IR strobe, panel, chem-light, other
  6. Remarks

MIST - the casualty's hand-over

  1. Mechanism of injury and time
  2. Injuries sustained
  3. Symptoms and vitals
  4. Treatment given

CONTACT REPORT (TIC) - broadcast to the side, marks the map

  1. Location
  2. Enemy
  3. Friendly casualties
  4. Intentions
  5. Assistance required

CONTACTREP (SALUTE) - goes to the intelligence picture

  1. Size
  2. Activity
  3. Location
  4. Unit
  5. Time
  6. Equipment

SITREP

  1. Call sign
  2. Location
  3. Enemy situation (and EKIA)
  4. Friendly situation (FKIA / FWIA)
  5. Civilian situation
  6. Status: ammo, casualties, vehicles, combat effectiveness - each green / amber / red / black

CALL FOR FIRE - opens a task, high priority

  1. Observer call sign
  2. Type of mission
  3. Size of element to fire
  4. Target location: grid, polar or shift
  5. Target description
  6. Method of engagement
  7. Danger close
  8. Method of fire control
  9. Time on target

CAS REQUEST - opens a task, high priority

  1. Grid
  2. Map reference
  3. Ingress
  4. Egress
  5. Target description
  6. Range from friendlies (danger close)
  7. Marked by: smoke, laser, IR, tracer, none
  8. Preferred munitions

AIRFRAME CHECK-IN

  1. Airframe call sign
  2. Number and type of aircraft
  3. Position and altitude
  4. Ordnance
  5. Time on station
  6. Abort code

HLZ BRIEF - opens a task

  1. HLZ location
  2. LZ name / map marking
  3. Extract contents
  4. Security: green / yellow / red
  5. Marking method
  6. Ingress
  7. Egress

AIRDROP BRIEF - opens a task

  1. Point of impact
  2. Point of impact altitude
  3. DZ description / mark
  4. Friendlies location / mark
  5. Surface winds
  6. Ingress
  7. Egress

VEHICLE REPORT (DEFREP)

  1. Vehicle
  2. Damage, equipment, fuel - each green / yellow / red / black
  3. Routing: tick CMD to copy the command group

REACT / QRF LINK-UP - opens a task

  1. Who links with who
  2. Link-up location
  3. Suggested route
  4. Special attachments needed
  5. Action on arrival

OPORD and METT-TC

The OPORD card carries the five paragraphs and the ROE; METT-TC is for leaders and pre-fills mission, enemy and civil from the current OPORD.
